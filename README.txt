GASTORA DRUG - GitHub Pages starter package
1) Upload index.html, drugs.json, and manifest.json to the ROOT of your gastora-drug repository.
2) Ensure the main page file is named exactly index.html.
3) GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.
4) Wait for deployment, then open https://YOUR-USERNAME.github.io/gastora-drug/

IMPORTANT:
- This package is a starter interface with 4 DEMO records only.
- It is NOT a verified drug database and does NOT contain 100,000 records.
- No real internet database downloader is connected yet. A published, licensed dataset and update manifest endpoint must be prepared before enabling automatic updates.
- Do not use demo records for clinical decisions.
